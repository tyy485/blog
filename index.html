欢迎来到我的小站。

我是一名喜欢折腾代码的开发者，平时大部分空闲时间都泡在各种各样的小项目里面。 最开始写代码只是出于好奇，想亲手做出可以在浏览器直接打开就能玩的小游戏。 从简单的贪吃蛇、小恐龙开始，一点点学习原生 JavaScript，研究游戏循环、碰撞检测、触屏适配。 慢慢之后，我不再只满足于做游戏，开始往别的方向探索：Python脚本、音频处理、自动化工具、开源项目。

在开发的路上踩过非常多坑。有时候一段代码调试整整一个晚上都找不到问题，有时候好不容易写完的功能，换一台设备直接就出现兼容bug。 但恰恰是这些不断试错的过程，才真正学到东西。我越来越喜欢写能够解决真实痛点的工具，而不只是用来娱乐的Demo。 makeotoini 就是这样诞生的项目，源于我自己在做UTAU声库的时候，反复手动编辑oto.ini带来的枯燥体验。

我建立这个网站，不打算写长篇大论的技术笔记，暂时更像一个自己作品的自留地。 我会把自己完成的项目集中放在这里，方便自己回看，也方便感兴趣的人直接体验。 我不会保证固定更新频率，有空的时候就写点新东西，或者回头维护旧项目。

如果你想查看我已经完成的作品，可以点开左上角菜单浏览。 所有开源项目的完整源代码，都可以在我的 GitHub 主页找到。

编程是一场漫长的摸索，不用急于求成，一步一步往前走就足够了。

其他开源项目

除了网页之外，我也在开发命令行工具与自动化脚本

makeotoini
维护中
一个用 Python 编写的 UTAU 声库 oto.ini 自动生成工具。 在制作 VCV 录音表声库时，手动为每一个音素配置 oto 参数是一件极其枯燥且容易出错的工作。 makeotoini 的目标就是把这部分重复劳动自动化，让声库制作者把精力放在更重要的调音与品质把控上。

核心功能

  • 支持 VCV 录音表的 oto.ini 批量自动生成
  • 内置日式中文发音特色的音素配置逻辑
  • 可自定义参数模板，适配不同风格的声库
  • 自动处理临时文件与中间产物，保持目录干净
  • 命令行交互，轻量无依赖，Termux 环境可直接运行
